## 繁體中文

這份預覽版集合 Yorunote 品牌、首頁候選、閱讀器快取修正，以及封面請求的佇列、取消與逾時保護。閱讀器及漫畫來源機制承襲 Venera；本分支的調整與上游功能分開記錄。

### 本次內容

- Yorunote 顯示名稱、角色圖示與 About 文案。
- 壞圖快取恢復、同鍵寫入競態防護及快取路徑重用修正。
- 快取命中繞過封面網路佇列，最多同時 8 個封面請求，同鍵共用。
- 取消傳遞及等待期間的快取一致性保護。
- 封面圖片每次 HTTP 嘗試原生總逾時 30 秒；保留既有重試。
- 合成漫畫來源與可控網路伺服器，供後續裝置驗收使用。

### 已有驗證與限制

- [CI run 41968314599](https://github.com/mengwen-liu/yorunote/actions/runs/41968314599)：完整測試 350 項、關鍵測試 68 項通過，0 跳過。
- Analyzer 維持 8 項既有 info，沒有新增 warning 或 error。
- APK 已完成 CI 靜態檢查；**這份 APK 尚未完成 S25+／Tab S11 實機驗收**。
- 30 秒不包括排隊、來源查詢與重試等待；4 次嘗試及等待可能合計約 134 秒，另加排隊。
- 慢速大封面若無法在單次 30 秒內讀完，會逾時並進入既有重試。
- 主機量測曾觀察到冷載整批完成時間約 9% 退步；不能外推手機 FPS 或耗電。
- 目前只有 Android ARM64 Profile 測試建置；不是 Release-mode 正式建置，也沒有其他平台的 Yorunote 成品。

## English

This preview combines Yorunote branding, the home-screen candidate, reader-cache fixes, and cover-request queueing, cancellation, and timeout protection. The reader and source system come from Venera; fork contributions are documented separately.

### Included work

- Yorunote display name, character icons, and About text.
- Invalid-image cache recovery and protection against concurrent replacement and path reuse.
- Cached covers bypass the network queue; at most 8 cover requests run concurrently and same-key loads share a request.
- Cancellation propagation and validation of cache entries written while queueing.
- A native 30-second total timeout for each cover-image HTTP attempt; existing retries are retained.
- A synthetic comic source and controllable server for subsequent device acceptance.

### Validation and limitations

- [CI run 41968314599](https://github.com/mengwen-liu/yorunote/actions/runs/41968314599): 350 full-suite tests and 68 key tests passed, with no skips.
- Analyzer diagnostics match the 8 existing infos, with no new warnings or errors.
- Static APK checks completed. **Runtime acceptance of this APK on the S25+ and Tab S11 is pending.**
- Queueing, source lookup, and retry delays are outside the 30-second timeout. Four attempts plus delays can take about 134 seconds, excluding queueing.
- Large covers on slow connections may time out and retry.
- Host measurements previously showed about a 9% cold-batch completion regression; this does not establish device FPS or power impact.
- Only an Android ARM64 Profile test build is available. This is not a Release-mode production build or a multi-platform release.

### Download and installation

The verified APK is currently in the CI artifact linked above. Until it is attached to a GitHub Release, these notes do not establish a permanent download.

The APK is 27,882,063 bytes. Its SHA-256 is `7ad08033c204a1de62546ca588ea0c050a5ace8ec0d4945d8c7978e156f5057f`.
The internal application version remains 1.6.3 (2163), regardless of the proposed GitHub preview tag.

**Signing compatibility:** the disposable test certificate differs from previous builds. It cannot update an installed app with the same package ID and a different signature. Preserve the existing installation and its data. A persistent signing/update channel has not been established.
