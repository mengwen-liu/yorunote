## 繁體中文

### 本次修正

- 修正 Windows 左上角顯示 `No Overlay widget found.`、精靈圖示被錯誤文字取代的問題。
- 為標題列提供所需的浮動圖層，保留精靈 GIF、滑鼠提示與無障礙名稱。
- 新增真實視窗框架的回歸測試，涵蓋提示顯示／消失、主題與視窗尺寸變更、頁面／對話框及隱藏／恢復標題列。
- 加入 Windows 原生滑鼠懸停驗收，確認提示關閉後動畫仍繼續播放。
- 保留既有視窗操作、資料目錄及相依套件；GIF 位元組未改。

### 使用者確認與驗證範圍

- 使用者於 **2026-11-07（Asia/Taipei）明確回報精靈動畫與滑鼠提示正常**，分類為使用者實機回報（OWNER_REPORTED），只涵蓋這兩項 UI 行為。[回報紀錄](https://github.com/mengwen-liu/yorunote/blob/2d0d5375f5e4f53f96f3558ad10278a7762c8797/docs/verification/windows-overlay-fix-20261106/OWNER_ACCEPTANCE.md)。
- [Windows CI 42229100772](https://github.com/mengwen-liu/yorunote/actions/runs/42229100772)：13 項指定測試通過、0 跳過，指定分析與格式檢查通過。
- 已實際啟動 ZIP 裡的一般程式並執行原生滑鼠懸停；同來源另建的驗收入口通過首次程序 11 項、重啟 4 項檢查，包含原生 HTTP、QuickJS／onResponse、閱讀、鍵盤翻頁、五頁下載、SQLite 及重啟離線閱讀。
- [另行下載核對 42231651219](https://github.com/mengwen-liu/yorunote/actions/runs/42231651219)：ZIP、校驗檔、54 份清單檔案、21 個 AMD64 PE 檔案及原始 GIF 相符。
- 本次發行沿用上述成品，沒有重新建置或重跑完整測試；沒有從使用者電腦回讀檔案雜湊。
- 所有第三方來源、WebView2 登入、多螢幕、各種 DPI、長時間使用及 Windows ARM64 尚未完整驗證。公開證據只使用 CI 合成資料，未附使用者私人漫畫畫面。

## English

This preview fixes `No Overlay widget found.` replacing the elf in the Windows caption. The frame now provides the Overlay needed by its tooltip. The original GIF, tooltip, accessible name, window controls, data directory and dependencies are retained.

Three regression tests exercise the actual frame outside Navigator, including hover, route/dialog state, theme/size changes and hiding/restoring the caption. Native Windows mouse input verifies tooltip appearance, dismissal and continued animation.

On **2026-11-07 (Asia/Taipei), the user explicitly confirmed the elf animation and mouse tooltip work normally**. This is a user-reported check of those two UI behaviors, not complete device acceptance. [Confirmation record](https://github.com/mengwen-liu/yorunote/blob/2d0d5375f5e4f53f96f3558ad10278a7762c8797/docs/verification/windows-overlay-fix-20261106/OWNER_ACCEPTANCE.md). No file hash was read from the user's computer.

Windows CI passed 13 focused tests with no skips. The extracted production executable was launched, hovered and normally closed. A separate acceptance entry point from the same source passed 11 initial-process and 4 restart checks covering native HTTP, QuickJS/onResponse, reading with keyboard input, five-page downloads, SQLite and offline reading after restart. Separate download verification checked the ZIP, checksum, all 54 manifest-listed files, 21 AMD64 PE files and the unchanged GIF.

Publication reuses those existing files without rebuilding or rerunning the full suite. All third-party sources, embedded web login, multiple monitors, all DPI settings, long sessions and Windows ARM64 remain outside full coverage. Public screenshots use synthetic fixtures only.

Download the two attached files, close the previous app, verify the checksum and extract the complete ZIP. Keep the executable, DLLs and data together, then run `Yorunote/yorunote.exe`. This unsigned preview has no installer and does not migrate or delete existing Venera data.
